Trady 요구사항 정의서 작성 지침 v2
1. 작성 목적
Trady 프로젝트의 User Story를 기반으로 시스템에서 구현해야 할 기능과 세부 동작을 구체적으로 정의한다.

요구사항은 기능 영역별로 구분하며, 개발 과정에서 구현 범위를 확인하고 테스트 기준으로 활용할 수 있도록 작성한다.
2. 엑셀 컬럼 구성
순서	컬럼명	작성 기준
1	번호	요구사항 순번 (1, 2, 3...)
2	요구사항 ID	기능별 영문 약어 3자리 + 일련번호 3자리
3	구분	요구사항이 속한 기능 영역
4	상세	요구사항의 기본 설명 및 세부 조건을 개조식으로 작성
5	요구 부서	프론트엔드 / 백엔드
6	중요도	상 / 중 / 하
7	협의 사항	초기에는 공란으로 유지

3. 요구사항 ID 작성 규칙
기능 영역을 나타내는 영문 약어 3자리와 일련번호 3자리를 조합하여 요구사항 ID를 부여한다.

작성 형식: XXX-001
기능 영역	식별자	ID 예시
주식 정보	STK	STK-001
차트 조회	CHT	CHT-001
주문	ODR	ODR-001
체결	EXE	EXE-001
D+2 결제	STL	STL-001
계좌	ACC	ACC-001
회원	MEM	MEM-001

작성 규칙
- 동일한 기능 영역에서는 일련번호를 순차적으로 증가시킨다.
- 기능 영역이 달라지면 일련번호를 001부터 시작한다.
- 이미 부여한 ID는 요구사항의 순서가 변경되더라도 유지한다.
- 삭제된 요구사항의 ID는 재사용하지 않는다.
4. 상세 작성 규칙
상세 컬럼은 기본 설명 + 세부 요구사항으로 구성하며 개조식으로 작성한다.

작성 기준
- 첫 줄에는 요구사항의 명칭을 작성한다.
- 하위 항목에는 구체적인 시스템 동작과 처리 조건을 작성한다.
- 하나의 요구사항에는 하나의 주요 기능 또는 책임을 정의한다.
- 모호한 표현을 지양하고 실제 구현 및 테스트에서 확인할 수 있도록 작성한다.
- User Story에 정의되지 않은 기능은 임의로 추가하지 않는다.
작성 예시
지정가 매수 주문
- 사용자는 종목, 주문 가격, 주문 수량을 입력하여 매수 주문을 요청할 수 있어야 한다.
- 시스템은 주문 가격과 수량의 유효성을 검증해야 한다.
- 주문가능금액이 부족한 경우 주문을 거부해야 한다.
- 정상적으로 접수된 주문은 주문 상태를 관리해야 한다.

5. 요구 부서 작성 규칙
요구사항의 구현을 담당하는 영역을 기준으로 구분한다.
구분	작성 기준
프론트엔드	화면 구성, 사용자 입력, 데이터 표시, UI 동작
백엔드	API, 비즈니스 로직, 데이터 처리, 데이터 정합성

프론트엔드와 백엔드 모두 관련되는 기능은 각 영역의 책임을 구분하여 별도의 요구사항으로 작성하는 것을 원칙으로 한다.
6. 중요도 작성 규칙
요구사항의 구현 필요성과 프로젝트 핵심 기능과의 관련성을 기준으로 상·중·하를 부여한다.
상
필수 핵심 기능


중
일반 기능


하
선택적 기능



중요도	배경색	글자색
상	#FEE2E2	#B91C1C
중	#FFEDD5	#C2410C
하	#FEF9C3	#A16207

작성 규칙
- 상: 프로젝트 핵심 기능 및 정상적인 서비스 동작에 필수적인 요구사항
- 중: 주요 기능을 보완하거나 일반적인 사용성을 제공하는 요구사항
- 하: 핵심 기능과 직접적인 관련성이 낮거나 후순위로 구현 가능한 요구사항
- 중요도 셀에만 지정된 배경색과 글자색을 적용한다.
- 중요도는 텍스트와 색상을 함께 표시한다.
7. 협의 사항 작성 규칙
초기 요구사항 정의 단계에서는 모든 협의 사항을 공란으로 유지한다.

추후 요구사항 변경, 구현 범위 조정, 추가 검토가 필요한 경우 해당 내용을 기록한다.
8. 엑셀 문서 작성 규칙
- 모든 요구사항은 하나의 시트에서 관리한다.
- 컬럼 순서는 번호 → 요구사항 ID → 구분 → 상세 → 요구 부서 → 중요도 → 협의 사항으로 고정한다.
- 상세 컬럼은 충분한 너비를 확보하고 자동 줄바꿈을 적용한다.
- 요구사항별로 하나의 행을 사용한다.
- 헤더 행은 고정하여 스크롤 중에도 확인할 수 있도록 한다.
- 각 컬럼에 필터를 적용하여 기능 영역, 요구 부서, 중요도별 조회가 가능하도록 한다.
- 중요도는 조건부 서식을 적용하여 상·중·하 입력 시 색상이 자동으로 변경되도록 한다.
- 협의 사항은 별도 요청이 있기 전까지 비워둔다.
